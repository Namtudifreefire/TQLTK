# GL-12 — localization audit

`gl12-localization-audit` is a portable .NET 10 check for the Vietnamese–English catalog.
It links the production `LocalizationAuditService` and `EnglishCatalog`, but deliberately does
not link WPF `LanguageService` or Windows APIs. A test-only language-state shim is used only to
compile the catalog audit on Linux.

The check verifies production catalog shape, stable IDs versus legacy `ui.<sha256>` IDs,
placeholder parity and escaped braces, Unicode validity, legacy-catalog conflicts, known/unknown
lookup behavior, and static source references to registered keys. Legacy source-string usage is
inventoried rather than treated as an error, because the migration is intentionally incremental.

The suite writes `artifacts/gl12/junit.xml`. WPF rendering, resource refresh and window-scale
behavior require Windows UI coverage and are intentionally outside this Linux job.
